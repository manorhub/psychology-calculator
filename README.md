**[Psychology Calculator](https://psychologycalculator.com)** is an evidence-based psychometric testing platform designed to turn self-assessment responses into actionable psychological insights. Built with modern web architecture (Astro 5, Tailwind CSS, Cloudflare Workers, Cloudflare D1, and R2), the platform delivers instant multi-dimensional score breakdowns, normative percentiles, and AI-powered psychometric reports.

## 🚀 Key Features

* ⚡ **Instant Multi-Dimensional Scoring** — Immediate dimensional percentage breakdown upon test completion.
* 🔒 **Privacy-First & Anonymous Testing** — Full guest mode support without requiring email or login to view results.
* 🤖 **AI Psychometric Dossiers** — Comprehensive, deep-dive personalized reports generated via advanced LLM engines.
* 🌍 **Multilingual Internationalization (i18n)** — Available in English, Spanish, French, German, Portuguese, and Hindi.
* 📱 **Mobile-Optimized & Accessible** — Clean, responsive UI crafted for seamless experience across mobile, tablet, and desktop.
* ⚡ **Global Cloudflare Edge Network** — Sub-50ms latency worldwide via Cloudflare Workers & Cloudflare D1 distributed database.
